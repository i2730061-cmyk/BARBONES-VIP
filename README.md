# Barbería Barbones VIP

Portada estática para presentar el informe del proyecto.

## Estructura
- `index.html`: contenido de la portada.
- `css/style.css`: estilos y diseño adaptable.
- `js/script.js`: interacciones sencillas.
- `fotos/`: imágenes que agregarás.
- `.github/workflows/pages.yml`: publicación automática en GitHub Pages.

## Agregar fotografías
Copia tus imágenes a `fotos/` con los nombres indicados en `fotos/README.txt`.

## Publicar en GitHub Pages
1. Crea un repositorio en GitHub.
2. Sube todos los archivos y carpetas, incluyendo `.github/workflows/pages.yml`.
3. En el repositorio abre **Settings → Pages**.
4. En **Build and deployment**, selecciona **GitHub Actions** si no quedó seleccionado automáticamente.
5. En la pestaña **Actions**, espera a que el flujo termine correctamente.
6. Abre la URL de GitHub Pages que aparece en **Settings → Pages**.

Este proyecto es una página estática: no guarda formularios, usuarios, citas ni pagos en una base de datos.
